# Tonora 0.17 — шесть возможностей по мотивам Scaler, Captain Chords, InstaChord и Live 12

23 октября 2026. Пользователь: «делай все сразу, только качественно». Ниже — решения, принятые до кода.

## Общая модель: код аккорда

Последовательность хранила номера ступеней 0–6. Теперь это **код аккорда** (целое число):

| Код | Аккорд |
|---|---|
| 0–6 | ступень лада, как раньше (старые сохранения читаются без изменений) |
| 16 + ступень цели | побочная доминанта V7/x |
| 24 + ступень цели | тритоновая замена subV7/x |
| 32 + ступень | заимствованный из одноимённого лада (мажор ↔ натуральный минор) |
| 40 | неаполитанский ♭II |
| старшие биты (×256) | обращение: 0 — основной вид, 1 — терция в басу, 2 — квинта, 3 — септима |

Код не зависит от тональности: V7/ii в любой тональности — доминанта ко второй ступени. Все места, где ступень превращалась в аккорд, идут через одну функцию ядра `kv_code_chord`.

## 1. Аккорды вне лада

Новая вкладка инспектора «Вне лада» (между «Аккорды» и «MIDI»): три группы плиток — побочные доминанты, заимствованные (с неаполитанским), тритоновые замены. Плитка: щелчок — послушать и показать на клавиатуре и пояснение, двойной щелчок или «+» — добавить. Под плитками — пояснение: что это за аккорд, куда разрешается, какая нота чужая.

Движок: для аккорда вне лада мелодия берёт «гамму аккорда» — гамму лада, где соседняя к хроматическому звуку ступень заменена этим звуком (A7 в до мажоре: до → до-диез). Иначе мелодия играла бы до против до-диеза.

## 2. Готовые прогрессии

Кнопка со списком рядом с генератором: именованные обороты по группам (поп, джаз, классика, минор, хроматика). Применяются к текущей тональности; оборотам, которым нужен минор или мажор, тональность переключается на одноимённую с той же тоникой. ⌘Z возвращает прежнюю последовательность.

## 3. Обращения

В меню аккорда последовательности — «Обращение»: основной вид, терция, квинта, септима в басу. Имя аккорда получает бас через косую черту (C/E). Бас левой руки во всех фактурах — выбранный звук; блочные аккорды и прослушивание звучат в обращении.

## 4. Импорт MIDI

«Последовательность → Импортировать MIDI…» (⌘O) или перетаскивание .mid в окно. Файл разбирается с проверкой границ (повреждённый файл — сообщение, не падение). Тональность — по профилям Крумхансла (с учётом знаков при ключе из файла), аккорды — по тактам из каталога кодов. Ноты становятся дорожкой пиано-ролла, аккорды — последовательностью, темп и размер — из файла. Влезает до 16 тактов (8 аккордов по такту или по два); длиннее — обрезается с сообщением.

## 5. Аккорд одной клавишей

Флажок во вкладке MIDI. Клавиша (MIDI, компьютер, экранная) — ступень лада → звучит её аккорд с текущей сложностью гармонии от этой клавиши вверх; клавиша вне лада — одна нота. Держится, пока нажата клавиша.

## 6. Модуляции на круге

Наведение на чужой сектор круга: сектора общих аккордов обводятся, пузырь называет общие аккорды с функциями в обеих тональностях и опорный аккорд (ii или IV новой тональности, иначе vi) и его продолжение V7 → I.

## Не делается

VST/AU, хостинг инструментов, распознавание аудио, 12-тактовый блюз (больше восьми слотов).

## Дополнение 23 октября

- «Добавить» во вкладке «Вне лада» и MIDI: при 8 аккордах из 8 — «Заменить N-й» для выбранного слота, иначе «8 из 8» с объяснением.
- Генератор: число аккордов (4/6/8) выбирается рядом с кнопкой; «Дополнить: ещё N» в пустых слотах и ⇧⌘N продолжают последовательность (`kv_generate_more`); каждая генерация берёт новую вариацию рисунка, свежий оборот может начинаться с любого своего аккорда.
- Звуки аккордов вне лада называются по буквам аккорда (F♯♯ вместо G; 𝄪 в системном шрифте нет).
