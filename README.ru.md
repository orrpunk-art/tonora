# Tonora

[English](README.md) | **Русский**

Интерактивный квинтовый круг для macOS. Выберите тональность на круге, послушайте её аккорды, соберите последовательность и сыграйте её аккордами блоком, в две руки на фортепиано, арпеджио или струнными — а потом заберите в DAW как MIDI.

Нативное приложение для macOS 12 и новее, Universal (Apple Silicon и Intel). Музыкальное ядро и сэмплер написаны на C11, интерфейс — на Objective-C / AppKit. Без сторонних фреймворков и без сети: все инструменты встроены.

![Tonora: квинтовый круг, аккорды до мажора, последовательность C – Am – F – G в две руки](design/screenshots/tonora-ru.png)

## Возможности

- **Квинтовый круг.** Внешнее кольцо выбирает мажорную тональность, внутреннее — параллельный минор. Девять ладов (мажор, натуральный минор, дорийский, фригийский, лидийский, миксолидийский, локрийский, гармонический и мелодический минор) и обе пентатоники. Наведите на другую тональность — круг покажет общие аккорды и путь модуляции.
- **Аккорды тональности** от трезвучий до терцдецимаккордов, с номерами ступеней, знаками при ключе и гаммой. Послушать — `1`–`7`, добавить — `⇧1`–`⇧7`.
- **Аккорды вне лада:** побочные доминанты, заимствованные из одноимённого лада, тритоновые замены, неаполитанский. Каждый аккорд объясняет, откуда он. Обращения — в контекстном меню аккорда.
- **Последовательности.** Восемь слотов, генератор (`⌘N`), который пишет новые аккорды в текущей тональности и ладу, и готовые прогрессии: поп, джаз, классика, минор.
- **Фактуры.** Аккорды блоком, фортепиано в две руки в девяти стилях (баллада, Альберти, вальс, дарк-джаз, трип-хоп, эмбиент…) с вариациями и проигрышами, арпеджио пяти рисунков и четыре струнные фактуры (хорал, кантилена, остинато, пиццикато).
- **Четыре инструмента:** рояль Salamander, Yamaha CP80, Hohner Pianet T и струнные VSCO 2 с легато, спиккато, пиццикато и динамикой колесом модуляции. Реверберация и дилей, синхронный с темпом.
- **Метроном и бит** — играть поверх с MIDI-клавиатуры (`⌘K`): клик на доли, восьмые, триоли или шестнадцатые либо бит на живых барабанах — поп, баллада, босса-нова, шаффл, хип-хоп, трип-хоп, хаус или бит по стилю рисунка. Идёт сам по себе или вместе с последовательностью, по желанию — с отсчётом такта.
- **Полифония 256 голосов** с отбором тихих голосов и педалью, под которой повторный удар дозвучивает.
- **Пиано-ролл** для правки сгенерированной партии по нотам: сетка, перетаскивание, растяжение, квантование, отмена, замедленное воспроизведение.
- **MIDI везде.** Сохранить `.mid`, перетащить клип прямо на дорожку DAW, отправлять ноты в виртуальный порт «Tonora», играть с MIDI-клавиатуры (по желанию — аккорд одной клавишей) или импортировать MIDI-файл — тональность, размер, темп и аккорды определятся сами.
- **Для обучения:** анимированные руки с аппликатурой, клавиатура компьютера как пианино (`M`), карточка со всеми сочетаниями клавиш и страница о том, как устроен круг (`⌘/`).
- **Русский и английский.** Язык интерфейса — по системе; переключатель — в окне FX (`⌘,`).

Тональность, последовательность, фактура, звук и положение окна сохраняются между запусками.

## Установка

Скачайте `Tonora-<версия>-universal.zip` в [релизах](../../releases), распакуйте и перенесите `Tonora.app` в «Программы».

Приложение подписано локально, без Apple Developer ID, поэтому при первом запуске macOS спросит: правый щелчок по `Tonora.app` → **Открыть**.

## Сборка из исходников

Нужны macOS, инструменты командной строки Xcode и CMake 3.20+.

```sh
./scripts/build.sh build-universal     # настроить, собрать arm64 + x86_64, прогнать тесты
open build-universal/Tonora.app
./scripts/package.sh                   # подписанный архив в dist/
```

Проект открывается в CLion как обычный CMake-проект (цель `Tonora`).

## Сочетания клавиш

| Клавиши | Действие |
|---|---|
| `←` `→` | соседняя тональность на круге |
| `↑` `↓` | мажор / минор на той же тонике |
| `⌥↑` `⌥↓` | предыдущий / следующий лад |
| `1`–`7` · `⇧1`–`⇧7` | послушать ступень · добавить её в последовательность |
| `Пробел` · `Esc` | играть / стоп · стоп |
| `T` · `L` | тоника · повтор |
| `⌫` · `⌘←` `⌘→` | удалить выбранный аккорд · переставить его |
| `⌘↑` `⌘↓` | регистр клавиатуры |
| `⌘N` · `⇧⌘N` | новые аккорды · дополнить последовательность |
| `⌘Z` · `⌘R` | вернуть предыдущую последовательность · новая вариация рисунка |
| `⌘C` · `⇧⌘O` | скопировать MIDI-клип · импортировать MIDI-файл (или перетащите `.mid` в окно) |
| `⌘O` · `⌘S` · `⇧⌘S` | открыть · сохранить · сохранить как файл песни `.tonora` |
| `⌘1` `⌘2` `⌘3` · `⇧⌘A` | круг · пиано-ролл · аранжировщик · отправить последовательность в аранжировщик |
| `⌘-щелчок` · `⌘T` · `⌘D` | аранжировщик: разрезать секцию по такту · разрезать под курсором · дублировать |
| `⇧⌘E` | экспорт песни в MIDI |
| `⌘K` | метроном вкл / выкл (Esc выключает его вместе с игрой) |
| `⌘,` · `⌘/` | звук и язык · все сочетания и справка |
| `M` | играть с клавиатуры компьютера: `A`…`'` белые клавиши, `W E T Y U O P` чёрные, `Z X` октава, `C V` сила удара |

## Устройство проекта

| Путь | Что там |
|---|---|
| `src/music.c` | тональности, лады, написание нот, аккорды и их коды, пояснения |
| `src/performance.c` | фактуры: рисунки двух рук, арпеджио, струнные, штрихи |
| `src/fingering.c` | аппликатура для анимированных рук |
| `src/mixer.c`, `src/piano.c`, `src/effects.c`, `src/audio.c` | сэмплер на 64 голоса, банки записей, реверберация и дилей, вывод через AudioQueue |
| `src/midi.c`, `src/midiio.m` | MIDI-файлы, вход и выход CoreMIDI |
| `src/main.m` | окно: круг, инспектор, клавиатура, последовательность, FX, самопроверка |
| `src/pianoroll.m`, `src/controls.m` | пиано-ролл; собственные элементы управления, глифы и подсказки |
| `src/strings_en.m` | английские строки интерфейса (ключ — русский текст в коде) |
| `assets/` | записи инструментов с лицензиями и контрольными суммами |
| `design/` | ТЗ, иконка, логотип, скриншоты |
| `tests/` | тесты ядра, сэмплера, фактур, MIDI и аппликатуры; проверка таблицы строк |

`ctest --test-dir build-universal` запускает восемь наборов, в том числе `Tonora --self-test`: настоящее окно на 50 размерах, оба языка, воспроизведение, MIDI и сохранение настроек — со своим хранилищем настроек, так что ваши настройки не затрагиваются.
